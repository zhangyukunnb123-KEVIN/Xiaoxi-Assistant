> **专为海外留学生打造的全自动 AI 智能学习与生活管家**

## 💡 为什么选择小汐助手？



海外留学期间，你是否经常面临：



- 📧 **信息过载**：每天收到数十封 Gmail / Outlook 邮件，重要通知、Syllabus 变动容易被淹没？

- 📝 **手动录入耗时**：每次都要把 Canvas / Blackboard 里的作业 DDL 和课表逐个敲进日历，难以坚持？

- ⚠️ **隐形风险**：护照、签证（F-1 / 学习许可 / CAS）、I-20、OPT 或驾照到期时间完全忘了看，面临身份合规风险？



**小汐助手通过全自动 AI 流程，帮你彻底解放双手！**



---



## 🔥 核心功能亮点



### 1. 零手动输入 (Zero-Manual Entry)

授权连通 Gmail 与 Outlook，底层 AI 自动识别邮件通知及 Syllabus 变动，无需任何手动抄写。



### 2. 课程表与作业 DDL 智能整合

自动提取作业提交截止时间（DDL）、Quiz、Exam 与上课节点，一键同步生成统一视图的结构化日历，并在关键时间节点精准提醒。



### 3. 证件与身份到期预警

智能识别护照、签证、I-20、Study Permit 等重要文件的截止日期，提前主动预警，规避留学身份风险。



---



## 🔒 隐私与数据安全 (Security & Compliance)



我们深知邮箱与个人身份数据的重要性。小汐助手在设计之初就将**数据安全与隐私保护**放在首位：



- 🛡️ **Google CASA 安全评估认证**：已全面通过严格的 Google CASA (Cloud Application Security Assessment) 安全审核。

- 🔐 **端到端隐私隔离**：仅提取与日程、DDL 和证件预警相关的元数据，绝不读取或储存非相关的私密邮件内容。

- 🚫 **无数据出售**：承诺绝不向任何第三方出售或提供用户的个人数据。
